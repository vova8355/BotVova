# 🤖 BOT VOVA — ТУТОРИАЛ

> **Что делает бот:** Бот следит за указанными чатами и когда кто-то пишет триггер (например, `/vova`) — автоматически отвечает от твоего аккаунта. Можно настроить разные ответы для разных людей.

---

## 🛠 ШАГ 1 — УСТАНОВКА

Для работы бота нужен **Python 3.11+**. Установи необходимые зависимости командой в терминале:

```bash
pip install telethon qrcode
```

---

## 🔑 ШАГ 2 — ПОЛУЧИ API_ID И API_HASH

1. Зайди на официальный сайт [my.telegram.org](https://my.telegram.org)
2. Войди через номер телефона своего аккаунта.
3. Нажми на раздел **"API development tools"**.
4. Скопируй появившиеся значения:
   * `App api_id` → это **ЦИФРЫ** (например: `12345678`)
   * `App api_hash` → это **СТРОКА** (например: `a1b2c3d4e5f6...`)

---

## ⚙️ ШАГ 3 — НАСТРОЙ config.json

Запусти бота один раз командой:
```bash
python BotVova.py
```
Скрипт автоматически создаст файл `config.json`. Открой его в текстовом редакторе и заполни по шаблону:

```json
{
  "api_id": 12345678,
  "api_hash": "a1b2c3d4e5f6...",
  "session_name": "userbot",
  "trigger": "/vova"
}
```

* 📌 `api_id` — **ЦИФРЫ БЕЗ КАВЫЧЕК** с сайта my.telegram.org.
* 📌 `api_hash` — **СТРОКА В КАВЫЧКАХ** с сайта my.telegram.org.
* 📌 `session_name` — название сессии, можно оставить по умолчанию (`"userbot"`).
* 📌 `trigger` — сообщение, на которое бот будет автоматически триггериться и отвечать.

### 💬 ЧАТЫ — `target_chats`
Список чатов, где бот будет слушать триггер. Можно вписывать числовой ID чата или `@юзернейм` (обязательно в кавычках!):

```json
"target_chats": [-1002200244541, "@BabizyanChat"]
```
* **ID чата** — отрицательное число (его можно узнать через технического бота `@username_to_id_bot`).
* **@юзернейм** — **ОБЯЗАТЕЛЬНО** оборачивается в двойные кавычки `""`.
* Несколько чатов внутри квадратных скобок разделяются запятой.

### 🎲 ОТВЕТЫ ПО УМОЛЧАНИЮ — `default_replies`
Это ответы для всех, кто пишет триггер (кроме тех пользователей, у кого настроен личный персональный ответ). Параметр `"weight"` отвечает за шанс выпадения фразы.

```json
"default_replies": [
  { "text": "привет",            "weight": 47.5 },
  { "text": "приает",            "weight": 47.5 },
  { "text": "привет, как дела?", "weight": 5.0  }
]
```
* `"text"` — текст твоего ответа в кавычках.
* `"weight"` — вес/шанс фразы (число). Сумма весов не обязательно должна быть равна 100, система оценивает их соотношение между собой (например, 5 из 100 итого даст примерно 5% вероятности).
* Чем больше число веса — тем чаще бот будет выбирать именно этот ответ.

### 👤 ПЕРСОНАЛЬНЫЕ ОТВЕТЫ — `personal_replies`
Особый, уникальный набор ответов для конкретного человека. Можно указать его числовой ID или `@юзернейм`:

```json
"personal_replies": [
  {
    "user": "@TimaQM",
    "replies": [
      { "text": "привет тимоша", "weight": 70 },
      { "text": "приает тиморла",   "weight": 30 }
    ]
  },
  {
    "user": 1624024189,
    "replies": [
      { "text": "привеооо", "weight": 100 }
    ]
  }
]
```
* `"user"` — числовой ID пользователя (цифры без кавычек) или его `"@юзернейм"` (в двойных кавычках).
* `"replies"` — список фраз с индивидуальными весами (настраивается точно так же, как и блок дефолтных ответов).
* Узнать точный ID человека можно через бота `@userinfobot` в Telegram.
* Если персональные ответы тебе не нужны, оставь поле пустым: `"personal_replies": []`.

## ⚠️ ВАЖНЫЕ ПРАВИЛА JSON (иначе код выдаст ошибку!)

* ✅ **Юзернейм в кавычках:** `"@BabizyanChat"`  
  ❌ *Юзернейм без кавычек:* `@BabizyanChat`
* ✅ **api_id без кавычек:** `"api_id": 12345678`  
  ❌ *api_id в кавычках:* `"api_id": "12345678"`
* ✅ **Запятая между элементами списка:**
  ```json
  { "text": "привет", "weight": 47.5 },
  { "text": "приает", "weight": 47.5 }
  ```

## 🚀 ШАГ 4 — ПЕРВЫЙ ЗАПУСК И ВХОД

Запусти итоговый скрипт:
```bash
python BotVova.py
```

При первом запуске бот в консоли предложит выбрать способ авторизации:
1. **1 — QR-код** (открой мобильный Telegram: *Настройки → Устройства → Подключить устройство* и отсканируй QR-код из терминала).
2. **2 — Код из Telegram/SMS** (введи номер телефона в международном формате и дождись системного кода авторизации).

После успешной авторизации в папке проекта автоматически создастся файл `userbot.session` — это твоя сохраненная рабочая сессия. Повторно входить в аккаунт при перезапусках не потребуется.

> 🔴 **ВАЖНО:** Если ты удалишь файл `userbot.session`, авторизация слетит и процедуру входа через QR или СМС придется проходить заново.
